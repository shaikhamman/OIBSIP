# Oasis Infobyte (OIBSIP) — Temperature Converter (Level 1, Task 3)

## Overview
An interactive temperature conversion tool built using HTML5, CSS3, and Vanilla JavaScript that converts values between Celsius (°C), Fahrenheit (°F), and Kelvin (K).

## Features Implemented
- Numeric input validation with clear error messages
- Input unit selector (Celsius, Fahrenheit, Kelvin)
- Simultaneous output display for all three temperature scales
- Absolute zero boundary validation (-273.15°C / 0 K)
- Centered, responsive card UI
